# Security policy

## Supported versions

Only the latest released version of `aucreshape` receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/ibouftini/AUCReshaping/security/advisories/new)
or email imadbouftini04@gmail.com. You should get a reply within a week. `aucreshape` is a
pure-Python loss library with no network or file I/O in its core, so most reports will
concern dependencies or the examples.
